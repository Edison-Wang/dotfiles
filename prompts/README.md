# prompts/

工具無關的 prompt 模板。每個檔案可直接複製貼上到任何 AI 工具（Claude、ChatGPT、Gemini）。

## 命名規則

`stage-{N}-{用途}.md` — 對應 SDLC 階段。

## 使用方式

1. 開啟對應的 AI 工具
2. 打開模板檔案
3. 填入 `[方括號]` 標記的變數
4. 貼進對話
5. 實戰後回來更新模板

## 啟用狀態

目前啟用的 stage：

- `stage-1-ideation.md` — 需求發想
- `stage-3-spec.md` — 技術規格
